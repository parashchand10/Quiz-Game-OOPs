# Quiz-Game-OPPs
The Guess Game is a beginner-friendly, console-based Python application designed to demonstrate fundamental programming and Object-Oriented Programming (OOP) concepts. The game interacts with the user by presenting simple animal-related questions and evaluates responses in real time.

# Features

1. Object-oriented design using classes and methods
2. Multiple questions handled via a dictionary
3. Real-time score calculation
4. Clean and beginner-friendly code structure

# Concepts Used

1. Classes & Objects
2. Loops and Conditional Statements
3. Dictionaries
4. User Input Handling
